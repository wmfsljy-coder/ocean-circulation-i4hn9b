# 해수의 순환

학생이 직접 조작하며 배우는 해수의 순환 인터랙티브 학습 화면(`index.html` 한 장).

- 바로 열기: https://wmfsljy-coder.github.io/ocean-circulation-i4hn9b/
- 대시보드 '과목별 첫 화면' 카드의 '해수의 순환' 링크가 이 주소다.

## 만드는 법·배포법

- 빌드 없음. `index.html` 을 고쳐 `main` 에 push 하면 GitHub Pages(가지 `main`, 폴더 `/`)가 1~2분 뒤 위 주소에 반영한다.
- 공개 저장소다. 학생 개인정보·비밀 값을 넣지 않는다.
